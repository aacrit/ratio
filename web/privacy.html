Privacy

Your photo

Your photo never leaves your browser, and it is never stored: not in a file, not in a database on this site, not anywhere in your browser, not even in this tab. The measuring models download once from this site and run in the tab; the photo is decoded, measured and read there, and is gone when you close or reload the page. Suggested looks are worked out the same way, and trying one recolours your photo inside the tab, in memory only. Nothing about the photo or a look is sent or counted, except that a reading took place and that a look was tried, and nothing is kept except as below.

While the tab stays open, the outfits you read are kept in memory so that moving from Read to the Rulebook and back, or switching between a few reads with the strip, does not make you read the same photo again. This includes the photo, in memory only: closing the tab, or reloading the page, clears it, exactly as above.

So that the Rulebook can mark your last reading on its instruments, and so that a reload can still show the numbers it found (as the chalk figure, since the photo itself is gone), the browser keeps that reading's rounded measurements, its results and, if you tried a look, the look's title, measurements and results beside them, in session storage: numbers and short labels, never the photo or any of its pixels. It is kept for this tab's session (a browser that restores or duplicates the tab keeps it too); Clear on the Rulebook page removes it. It is never sent anywhere.

Compact mode

The Compact toggle on the Read page is remembered on this device, in localStorage, so it does not need choosing again next time. It holds nothing about you beyond that one on/off choice, and nothing is sent anywhere.

What this site counts

Ratio counts how many times a small set of named events happen each day, such as a page view or a completed action, as totals. It does not record who did what, when a specific visit happened, or anything else that could identify you. This counting uses no anonymous id, no cookie, and no third-party analytics script.

The feedback form sends the text you type and the page you sent it from; the server stores them with the time the message arrived. Nothing else is attached to it. Please do not include your name, email, or other personal details in a feedback message.

Your connection

Every page, script, style and font comes from this site; nothing is loaded from another company. To stop abuse, the server limits how many requests one network can make in a short time. For that it uses your IP address (for an IPv6 address, only its network part) while answering the request: Cloudflare keeps a short-lived count in memory, and Ratio never stores or logs the address. Ratio keeps no log of ordinary requests: Cloudflare's per-request logs are turned off for this site, and Ratio's own code logs nothing about who asked or what was sent. Cloudflare, which hosts the site, still handles your IP address to deliver it, as any host does.

One exception: if one IP address sends more than 30 requests to voidvision.org sites in 10 seconds, Cloudflare's firewall blocks it for 10 seconds and records each blocked request (the IP address, the page asked for and the browser's user agent) in the site's security event log, which Cloudflare keeps for a limited time. That log is used only to see and stop abuse.

Retention

Daily event totals are kept indefinitely: a total identifies no one, so there is nothing in it to delete. Feedback text is kept for 90 days, then deleted automatically in batches on days the site is used. If the site goes unvisited for a while, deletion falls behind and catches up once visits resume. Cloudflare D1, the database Ratio uses, can restore itself to any moment in the last 7 days, so deleted feedback can remain in that restore window for up to 7 more days.

Deletion

Feedback text you sent can be deleted early on request, if you can describe it well enough to find (for example, the page and roughly when you sent it). Use the feedback form on the home page to ask.
